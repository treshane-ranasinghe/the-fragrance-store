# Images

Save your photos here with these exact names. `.jpg`, `.png`, `.jpeg` and `.webp` all work.
Until an image is added, the site shows a gold bottle placeholder in its place.

| File | What goes in it |
|---|---|
| `hero.jpg` | Boss Bottled Elixir on the gold pedestal (big hero image, right side) |
| `azzaro-gold.jpg` | Gold Azzaro bottle with raspberries ("Our Story" section) |
| `boutique.jpg` | A photo of your shop / counter ("Visit" section) |
| `products/boss-bottled-elixir.jpg` | Boss Bottled Elixir poster |
| `products/azzaro-most-wanted-parfum.jpg` | Azzaro The Most Wanted Parfum poster |
| `products/jpg-le-male-elixir.jpg` | Jean Paul Gaultier Le Male Elixir poster |
| `products/lattafa-khamrah.jpg` | Lattafa Khamrah bottle |
| `products/montblanc-explorer.jpg` | Montblanc Explorer lifestyle shot |
| `collection-her.jpg` | Any women's fragrance photo ("Pour Femme" card) |

To add a new product: put its photo in `products/<id>.jpg` and add an entry
with the same `id` in `js/products.js`.
